# Amazon S3

> Sample study notes for the offline demo. Simplified and written for this project; check the AWS documentation for current limits.

Amazon Simple Storage Service (S3) stores objects in buckets. An object is a file together with its metadata and is identified by a key inside the bucket.

## Durability and consistency

S3 Standard is designed for 99.999999999 percent durability, often called eleven nines. S3 provides strong read-after-write consistency: after a successful write, every read returns the new object.

## Storage classes

S3 Standard is for frequently accessed data. S3 Standard-IA and S3 One Zone-IA cost less for data that is read rarely. S3 Intelligent-Tiering moves objects between tiers automatically when access patterns change. S3 Glacier Instant Retrieval, S3 Glacier Flexible Retrieval and S3 Glacier Deep Archive are for archives, and Deep Archive has the lowest storage cost.

## Versioning

With versioning enabled, S3 keeps every version of an object. A delete adds a delete marker and earlier versions can be restored.

## Lifecycle rules

A lifecycle rule moves objects to a cheaper storage class or expires them after a number of days. Lifecycle rules are the usual way to archive raw data automatically.

## Event notifications

A bucket can send an event when an object is created or removed. The destination can be an SQS queue, an SNS topic, a Lambda function or Amazon EventBridge.

## Multipart upload

Multipart upload sends a large object in parts that can be retried independently. It is recommended for objects larger than 100 MB.
